# Harness logos

Locally bundled on September 3, 2026. These marks identify the integrated harnesses; they belong to their respective owners.

- `codex.svg`: OpenAI's black monochrome Blossom, unchanged from `OpenAI-logos(new)/SVGs/OpenAI-black-monoblossom.svg` in the [official logo download](https://cdn.openai.com/brand/OpenAI-Logos-2025.zip). [Brand guidelines](https://openai.com/brand/). The black mark is inverted to white in the dark theme.
- `claude.svg`: the standalone orange symbol path from the Claude wordmark on [Claude's official website](https://claude.com/), retaining its original path and `#D97757` color.
- `pi.svg`: the official compact [Pi badge](https://pi.dev/favicon.svg), unchanged, from the [Pi press kit](https://pi.dev/press-kit).

The app serves these files itself. Rendering a harness logo makes no requests to third-party image hosts.
